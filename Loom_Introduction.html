1. Define a model

Excerpt from the actual C# demo model. IDs are permanent, even when names change.

[Document("cc000000000000000000000000000001",
    nameof(Name), Name = "TestResult")]
[Grant("Admin", "read", "create", "write",
    "delete", "audit")]
[Grant("Viewer", "read")]
public sealed class TestResultModel
{
    [Field("cc000000000000000000000000000002",
        Required = true)]
    public string Name { get; set; } = "";

    [Field("cc000000000000000000000000000003",
        Options = new[]{"Pass","Review","Fail"},
        Required = true)]
    public string Outcome { get; set; } = "Pass";

    [Field("cc000000000000000000000000000005",
        Currency = "USD", Precision = 19, Scale = 2)]
    public decimal? Cost { get; set; }
}

WHAT BELONGS WHERE
Loom is more than an ORM.
Loom
Model identities, forms, validation, permissions, hooks, reports, audit policy and scientific values.
EF Core
PostgreSQL and SQL Server mapping, CRUD, transactions and version checks. Loom supplies the dynamic-field query semantics.
Your database
Durable data and transaction isolation. Choose Memory for disposable runs, SQLite locally, or a server provider.
What is implemented—and what is still open?
  • Working: configurable storage, exact money, measurement values with units and uncertainty, binary fields, audit history, and the SQLite model/report designers.
  • Server queries: numeric filtering, sorting and paging run in the database. Text queries retain a bounded scan; useful indexes remain open work.
  • Schema evolution: SQLite supports reviewed migration plans. Server providers currently reject application schema changes. Switching providers does not transfer data.
  • Prototype limits: the demo role selector is not authentication. Production authentication, finer permissions and operational hardening remain unfinished.
  • Binary data: SQLite has transparent blob compression. The current server JSON provider does not offer the same compressed-blob storage.


RUN THE ACTUAL FRAMEWORK
The browser is the interface.
C# does the framework work.
From the Loom repository with the .NET 8 SDK installed:
dotnet run --project src/Loom.Demo -- --memory-demo
Open http://127.0.0.1:5080/introduction.html for this page connected to C#, or the full application for measurement editing, binary upload and more. Memory data disappears when the host stops.
For persistent scientific records, configure a database and run with --science-demo. Use Database__Provider (Sqlite, PostgreSql or SqlServer) and Database__ConnectionString. The host remains loopback-only.
No application JavaScript is required to define your C# model. This introduction contains JavaScript to render the form and call the API; its standalone edition also includes an explicitly labeled simulation.
