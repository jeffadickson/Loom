01 / Highest priority

Quantities, units and uncertainty

A measurement needs a quantity kind, original unit and uncertainty definition. Convert only compatible dimensions. Treat temperature offsets correctly, and keep standard uncertainty distinct from tolerance and expanded uncertainty.

Quantity<Temperature> · value · unit · uncertaintyKind · u · coverageFactor
02 / Traceability

Runs and provenance

Link results to instrument serial number, calibration revision, procedure, specimen, operator and software version. A derived result points to its input records and processing parameters; raw data stays unchanged.

Result → Run → Instrument + Calibration + Procedure
DerivedResult → InputIDs + AlgorithmVersion + Parameters
03 / Efficient data

Typed arrays and chunked storage

Store shape, axes, units, numeric type, byte order, scaling and missing-value rules with the bytes. Add chunk-level compression and checksums for partial reads. Support IEEE floating point for measurements; retain decimal for money.

dtype: int32 · endian: little · shape: [512]
scale: 0.001 °C/count · axis: elapsed seconds
04 / Time and quality

Explicit timing and quality masks

Record the time scale, epoch, timestamp resolution, clock source and synchronization uncertainty. Support irregular sample times, gaps, saturation and invalid samples. Filtering changes the analysis selection, never the raw record.

t₀ + Δt, or timestamp array · timeScale · clockID
quality: valid / missing / saturated / suspect
05 / Scientific interchange

External datasets and export

Extend URI references with dataset path, channel, time range, revision and credentials stored separately. Add adapters for HDF5/NeXus and chosen time-series systems. Import/export should preserve units, axes and provenance.

DatasetRef(provider, uri, path, revision, channels, timeRange)
06 / Honest status

What exists versus this preview

Loom v0.12 has scalar fields, exact money, migrations, audit history, bounded blobs with transparent SQLite compression, and URI storage. C# quantity/uncertainty primitives now exist. Native quantity fields and UI integration, scientific arrays, chunking, immutable raw-data policy and external-store adapters remain open tasks.

This preview: filtering · units · quality masks · waveform inspection · real browser compression test

Design references: NeXus signals and axes · NIST reporting uncertainty. No external data is loaded by this demo.
